### Non-LLM models

Non-generative models are tracked in the dataset but are not included in the parameter ranking. Additions should include an explicit `ranking_excluded_reason`.

## How to use this repository

```bash
python -m pip install -r requirements.txt
python scripts/validate_data.py
python scripts/generate_readme.py
```

See [CONTRIBUTING.md](CONTRIBUTING.md), [the methodology](docs/methodology.md), and [the source guide](docs/sources.md) before changing model records.

## Caveats

NVIDIA catalog availability, endpoint quotas, model aliases, and free-tier policies change. A `Free Endpoint` label records the state observed on `last_verified`; it is not a guarantee of unlimited access. Always confirm the NVIDIA page and its current terms.
